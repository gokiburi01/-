# MemoFit — UIリニューアル版

「見出しを追加.zip」の画面デザインをもとに、Kei-main のUIを作り替えました。
白・黒、大きな見出し、斜めのボタン、円形の数字、カメラ上の表示を共通のスタイルでまとめています。

## 使い方

1. ZIPを展開し、`Kei-main` フォルダーを開きます。
2. `index.html` を開くと、開始画面・設定・記憶テストを操作できます。
3. カメラを使う運動は、HTTPSのWebサイト、または `localhost` のローカルサーバーで開いてください。
   VS Code の Live Server などを利用できます。Pythonがある場合は、このフォルダーで `python -m http.server 8000` を実行し、PCのブラウザから `http://localhost:8000` を開けます。
4. 「スタート」から性別・年齢層を選び、準備画面の「コース・表示設定」を選択してテストを開始します。身長・体重は任意です。
5. 運動開始時にカメラを許可し、全身が映る位置へ移動します。

ビルドやnpmのインストールは不要です。フォルダー内のファイルをまとめて設置してください。
スマートフォンからPCのLANアドレスにHTTPでアクセスすると、カメラが利用できない場合があります。スマートフォンでの運動にはHTTPSで配信してください。
運動判定のAI・モデルデータは運動開始時に読み込むため、インターネット接続が必要です。読み込みに失敗した場合は、準備画面の戻るボタンから再試行できます。

## 主な変更

- 開始画面をMemoFitのデザインに変更。
- 性別・年齢層を1画面ずつ選択するUIに変更。元の身長・体重入力も保持。年齢層の選択肢は「10代、20代、30代、40代、50代、60代、70代、80代、90代、その他」。
- 20桁の数字を円形のマスに配置。回答中も入力した数字をマスで確認可能。
- 運動前スコアを大きな数字で表示。
- 運動名と残り秒数を拡大。残り秒数はカロリーの左隣（初期設定）または右下に配置でき、秒数だけ・カロリーだけ・両方の表示を選べます。運動中にも表示ボタンで切り替えられます。
- 運動ごとに3秒の開始演出を追加。この間は運動時間を減らしません。
- 動くSVGマスコットを追加。運動ごとに動きを切り替えます。グーパー運動では、通常・休憩ありのどちらでも「自分のペースで！」の吹き出しを表示します。
- 斜めの画面ワイプ、段階的な表示、ボタンの波紋、数字の切り替え、スコアのカウントアップ、目標達成時の紙吹雪を追加。
- 右上の「MOTION」でアニメーションを切り替え可能。初回はOSの「視差効果を減らす」設定も反映。
- 運動前後の結果を比較して表示。正答率の差は「%」ではなく「ポイント」と表記。
- 「記録を見る」とCSV書き出しを実装。保存先は使用中のブラウザ内で、最大100件。
- 全角数字の入力に対応し、回答の二重送信を防止。
- 運動終了・中止・準備失敗時にカメラを停止。
- AIの読み込みを運動開始時に移し、最初の画面の操作を待たせない構成に変更。
- PC・タブレット・スマートフォンの画面幅に応じた配置を用意。

## 引き継いだ内容

- 数字の記憶テスト：準備10秒 → 20桁を15秒表示 → 順番どおりに回答。
- 正解数：各桁の位置が一致した数で採点。
- 運動の種類：グーパー運動、もも上げ、スクワット、ジャンプ。
- スクワット・ジャンプ・もも上げ・手の判定方法と、カロリー推定の計算方法。通常の目標は1セット15回です。
- 1セット40秒の運動時間。コースにより4セットまたは7セットを選びます。
- 運動を途中で終了し、運動後の記憶テストへ進む機能。
- MoveNetとMediaPipe Handsを使う運動判定。

## コース

準備画面で「3分／5分」と「通常／休憩あり」を選びます。各セットは40秒、各セットの前に3秒の準備表示があります。

| コース | メニュー（左から順番） |
| --- | --- |
| 3分・通常 | グーパー → もも上げ → スクワット → ジャンプ |
| 5分・通常 | グーパー → もも上げ → スクワット → ジャンプ → グーパー → もも上げ → スクワット |
| 3分・休憩あり | グーパー → もも上げ → スクワット → ジャンプ8回（残り時間は休憩） |
| 5分・休憩あり | グーパー → もも上げ → スクワット → ジャンプ8回（残り時間は休憩） → グーパー → 休憩40秒 → ジャンプ8回（残り時間は休憩） |

- 「3分コース」は4セットで、準備表示を含めて約2分52秒です。
- 「5分コース」は7セットで、準備表示を含めて約5分1秒です。
- 前後の記憶テストやAIの読み込み時間は別です。
- 休憩ありコースのジャンプは各セット8回が目標です。8回達成したら「休憩」へ切り替わり、そのセットの残り秒数が0になるまで休みます。まだ8回に達していなくても、40秒が経過したら次へ進みます。
- 40秒の休憩セットや、ジャンプ達成後の休憩中には回数・カロリーを加算しません。
- 回数表示と目標はセットごとに0から数え直します。結果画面では運動全体の合計を表示します。
- 選んだコースはテストを開始した時点で固定されます。設定の変更は次のテストから反映されます（表示位置と表示項目は運動中も切り替えられます）。

## 記憶テストの数字設定

「コース・表示設定」の「前後の記憶テストの数字」で選べます。

- **最初と最後を同じ数字にする**：最初に生成した20桁を、運動後にも同じ順序で表示します（初期設定）。
- **最初と最後を別々にランダム生成**：運動後に、新たに20桁すべてをランダム生成します。前の数字の並べ替えではありません。ランダムなので一部の桁が偶然一致することはあります。

途中で運動を終了した場合にも、選んだ数字設定で運動後の記憶テストに進みます。
コース・休憩の有無・数字設定・表示の設定は、同じブラウザで次回も引き継がれます。

参考画像にある「色のテスト」は、元のアプリに存在しないため追加していません。
画像内のロゴとマスコットは、今回の画面用にSVGで描き起こしています。元のベクターデータとの完全一致ではありません。

## 記録

完了時に、入力した性別・年齢層・任意の身長/体重と、テスト結果・運動回数・運動時間・推定カロリー・コース・休憩の有無・数字設定・セット数をブラウザに保存します。以前の版で保存した記録も残し、引き続き一覧とCSVで読み出せます。
このアプリのコードから参加者の情報やカメラ映像をサーバーへ送信する処理はありません。
AIライブラリ・モデルの取得には外部の配信元への通信が発生します。
ブラウザのデータ消去や保存機能の制限により記録が失われることがあるため、研究で使用する結果はCSVで書き出してください。
保存できなかった場合も、同じページを開いている間は記録画面からCSVを書き出せます。

## ファイル構成

- `index.html` — 画面の構造
- `app.css` — デザイン、レスポンシブ配置、アニメーション
- `app.js` — 記憶テスト、カメラ・AI、運動判定と進行
- `ui.js` — 画面演出、SVGマスコット、記録保存、CSV出力
- `assets/mark.svg` — MemoFitのシンボル
- `assets/mascot.svg` — マスコットのSVG原稿（実行時用はui.jsにも埋め込み）
